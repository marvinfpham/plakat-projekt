# Project instructions

This is the poster shop only. Do not edit Plomme or RecordsUp. Read CURRENT_STATUS.md, DECISIONS.md, ROADMAP.md, BACKLOG.md, BLOCKERS.md, COSTS.md and APPROVALS.md at session start. Use the existing checkout; each Codex cloud task is isolated, so do not create worktrees unless the owner explicitly requests one.

Development theme is in `theme/`, derived from Shopify Dawn 16.0.0. Validate with `npm ci`, `npm run theme:check`, `npm run theme:package` and `python -m unittest discover -s tests -v`. Shopify preview and checkout testing require store access. Do not publish a theme, product or artwork without exact owner approval. Do not purchase anything, place sample orders, start advertising or connect production order writes without specific approval.

Treat market claims and financial figures as either sourced facts, dated quotes, actuals or clearly marked estimates. Do not invent search volumes, prices or sales. Keep secrets out of source control. Do not use other AI engines or external AI agent platforms. Start with deterministic code and scoped Codex tasks; do not imply that a task session is a persistent autonomous worker.

Before unattended integrations, require signature verification, idempotency, bounded retries, reconciliation, alerts, a stop switch, version-specific artwork approval and auditable action records. Keep customer data out of agent tasks unless essential and authorized. Record work, tests, costs, blockers and next task in the continuity files at session end.
